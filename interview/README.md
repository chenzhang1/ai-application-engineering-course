## 2. 怎么用（四步）

1. **先读正文 12.0**：六段式答案结构（考查点→常见错误→简洁合格→深入解释→工程案例→追问与边界）与真题辨认的 A~E 分级——这决定了你刷题的姿势：任何"背答案"的题，先用 A 级来源（官方文档/SDK 源码/你跑出的运行记录）验一遍再背。
2. **每题三级用法**：先只看题面，口头给"30 秒合格版"（对应每题第 3 段）→ 展开到"深入解释"（第 4 段）→ 能挂到自己的项目（第 5 段）才算过。第 2 段（错误答法）留给自查，面试里永远不要说出来。
3. **与各章 N.11 的关系**：正文每章的"面试追问"是提示卡（思路与追问方向），本目录是完整解题过程——两者配合用，冲刺期先过 N.11 再进对应专题。
4. **每专题做完做"30 分钟自测"**：5 个口头回答题，每题 1 分钟思考+3~4 分钟回答并录音，按"评分要点"自评（每题 2 分：结构 1 分+事实 1 分）；错题记进复习队列，第二天复述一遍。

## 4. 三条使用红线（与全书一致）

1. **全部题目为[模拟题]**：不把本书题目当"真题"引用，面试中不声称"这是某大厂真题"。
2. **不承诺就业结果**：本目录提升的是知识结构、项目可复现性与表达纪律；offer 判断与薪资谈判不在本书范围。
3. **版本与事实**：引用版本号只来自教材 FACTS/requirements（如 langgraph 1.2.16、langchain 1.4.6、openai 3.35.1）；各厂商 API 行为、MCP 传输细节、模型价格以官方文档为准——面试里主动说"以官方文档与我实测为准"是加分项。
