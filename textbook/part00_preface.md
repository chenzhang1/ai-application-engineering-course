# 前言与全书导读

> 资料核实日期：2026-10-19。本教材所有关键依赖版本均在该日于隔离环境中实际安装并运行验证；版本事实记录于 `requirements.txt`、`requirements-lock.txt` 与 `sources.md`。

## 0.1 这套教材是什么、不是什么

**是什么：**

- 一套面向**有 Java 后端经验**的开发者的 Python AI 应用开发系统教材，覆盖语言基础、工程化、大模型 API、Prompt、RAG、LangChain、LangGraph、Agent/MCP、企业级架构与面试。
- 每个知识点按"真实问题 → 一句话解释 → 类比与类比边界 → 正式原理 → 可运行示例 → 排错 → 企业场景 → 练习 → 面试追问"的固定方法展开。
- 所有可运行示例都在本书约定的环境中实际执行过，输出可复现（模型相关示例默认 Mock 模式）。

**不是什么：**

- 不是入门科普、不是学习路线合集、不是资料索引。
- 不是模型训练教材：预训练/SFT/LoRA 只讲到"理解原理、判断适用场景"的必要深度（第十一部分）。
- 不能穷尽 AI 全部内容：本书覆盖的是"AI 应用工程师"岗位的核心知识，边界见 0.4。

## 0.2 给 Java 开发者的一句话定位

你已有的能力——接口设计、数据库、日志排查、Spring Boot 工程习惯、测试意识——大约能迁移 60%；剩下的 40%（Python 对象模型、asyncio、Pydantic 校验体系、LLM 的不确定性与上下文工程、LangGraph 的状态与恢复语义）是本书重点展开的部分，我们不会用大量篇幅重复讲所有语言共有的常识。

## 0.3 三种学习路径

1. **从头完整学习**（约 12 部分 + 3 项目，按顺序）。
2. **Java 加速路径**：ch01 → ch04~ch11（速读+做练习）→ ch13~ch20（精读）→ 卷二全部精读 → 项目随学随做。
3. **面试前冲刺**：每章"自测检查表 + 面试追问" → 第十二部分全部 → 每个项目"面试讲法"小节。

详细路径与章节依赖见 `syllabus.md`。

## 0.4 能力边界声明（诚实优先）

- **本书不承诺任何就业结果。** 目标是：你能开发、测试、部署和优化企业级 AI 应用，并能真实地讲清自己的设计、实现与验证过程。
- **"AI 应用工程师" ≠ "模型训练/算法研究工程师"。** 前者的核心是把不可靠的模型能力包装成可靠的服务：工程化、评估、安全、成本、可观测性。本书以后者为主。
- **教学环境可运行 ≠ 生产环境可上线。** 没有在真实生产流量下验证过的能力，本书不会声称你已具备；上线差异在第十部分集中讨论。
- **时间敏感内容的核实方法**：框架 API 演进很快，本书所有版本以 2026-10-19 实际安装为准；超过该日期后，请以官方文档为准并按 `sources.md` 的入口页核对。各章末尾设"待核实"小节列出该章编写时无法完全确认的点。

## 0.5 运行模式与诚实标注（全书约定）

| 标注 | 含义 |
|---|---|
| `# 真实运行输出` | 确定性程序在本环境实际执行的输出 |
| `# Mock 运行输出` | 离线假模型（不联网）下的真实执行输出 |
| `# 示例输出（非真实记录）` | 为教学编写的模型回答示例，非任何真实调用结果 |

- 本书示例统一双模式：`LLM_MODE=mock`（默认）与 `LLM_MODE=real`（需 `OPENAI_API_KEY`，兼容 OpenAI 接口的服务亦可，注意功能边界，见 ch24）。
- **Mock 模式只能验证程序控制流与接口契约，不能证明真实模型的回答质量与工具选择能力。**

## 0.6 环境与约定

- Python 3.12+（本书全部代码在 Python 3.14.7 上验证）；示例根目录 `examples/`，项目根目录 `projects/`。
- 依赖安装：`pip install -r requirements.txt`（版本已锁定并实际验证）。
- 示例编号全书唯一：`EX-<章>-<序>`，教材、源码、验证报告三方可对应。
- 术语规则：中文（English）+ 一句定义 + 一个例子；类比只用于建立直觉，边界必须写明。
