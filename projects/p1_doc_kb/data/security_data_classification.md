# 数据密级与外发管理（V2.1）

## 密级定义
公司数据分为三级：公开（官网内容、招聘信息）、内部（制度文档、周报、普通项目资料）、机密（源代码、客户合同、财务明细、薪酬数据）。未标注密级的默认按内部处理。

## 外发审批
内部数据外发给外部合作方，需部门负责人审批；机密数据外发需信息安全组与法务双重审批，并使用加密压缩加单独渠道传输密码。审批记录保存 3 年备查。

## 泄露处置
发现疑似泄露（截图外传、误发邮件、设备丢失）应在 2 小时内报告信息安全组，由其统一评估与处置，不得私自联系相关方。瞒报按机密数据外发未审批处理。
